basics of overiview and dxn

    I have done the following order in a course.
  • I start with the registration page!
  • then i create the log.css file to style the registration and login forms.
  • then I create the log_in.html file.
  • then I create the auth.js file which will handle the registration and login logic using localStorage.
  • then create the home.html page, which will be the main dashboard after login.
  • create the custom.css file for general styling of the website.
  • then create the courses.html page, which will display the content for each selected course.
  • then create the contact.html page.
  • finally the script.js file to handle dynamic content for the courses page and general page interactions.
